# Contributing

Thank you for contributing to this repository.

## Getting started

- Create a branch from `main`.
- Keep changes focused and small.
- Update related docs and indexes when adding or renaming files.

## Pull requests

- Use the repository pull request template.
- Include a clear summary, impact, and validation evidence.
- Keep placeholders for all credentials and tokens.

## Validation expectations

Before opening a pull request:

- Ensure markdown links resolve.
- Ensure numbered docs remain unique and sequential.
- Ensure GitHub Actions workflow YAML is valid.
- Ensure `VERSION` and `CHANGELOG.md` remain consistent when versioning
  changes.

## Security expectations

- Never commit real credentials.
- Keep examples in placeholder form only.
- Report security concerns through private disclosure channels.
