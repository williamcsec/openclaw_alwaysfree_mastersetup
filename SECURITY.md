# Security Policy

## Reporting a vulnerability

If you discover a security issue, do not open a public issue.

Please report it privately through GitHub Security Advisories for
this repository.

Include:

- Affected file(s) or document section(s)
- Reproduction details
- Potential impact
- Suggested remediation (if available)

## Response expectations

- Initial triage acknowledgment target: within 5 business days.
- Valid reports will be investigated and remediated through a
  tracked fix.
- If needed, sensitive operational examples will be replaced with
  safer placeholders.

## Scope

This repository is documentation and configuration focused.

Security concerns include:

- Secret exposure in examples, documentation, or scripts
- Unsafe operational guidance
- Insecure default configuration examples
